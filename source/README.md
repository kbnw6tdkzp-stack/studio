# Studio

An original, brand-focused design editor (canvas, templates, brand kit, export).

```bash
npm install
npm run dev        # http://localhost:5173
```

- **Customize**: edit `src/brand.ts` (name, colours, fonts) or use the Brand Kit panel in-app. Templates in `src/templates.ts`.
- **Cloud saving (optional)**: run `supabase/schema.sql` in a Supabase project, copy `.env.example` to `.env`, fill in the URL and anon key.
